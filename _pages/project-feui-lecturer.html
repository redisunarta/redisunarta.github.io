Universitas Indonesia · Data wrangling · 2019

The busiest FEUI lecturer

Every cancelled or rescheduled class at FEB UI was announced on Twitter. Read together, those announcements are a dataset about who cancels, and when.

The question

Biro Pendidikan FEB UI used its Twitter account to announce cancelled and rescheduled classes. Students read them one at a time. I wanted to read them all at once and look for a pattern: which lecturers cancelled most, and at what points in the semester.

What I did

Pulled the account’s tweets through the Twitter API, then turned free-text announcements into structured records — lecturer, course, date, and whether the class was cancelled or moved — using regular expressions.

The real objective

The main goal was to build data-wrangling skill. Announcement tweets are short, inconsistent and written by hand, which makes them a good training ground: most of the work is getting messy text into a shape you can count.

Data and tools

Data: Twitter API (Biro Pendidikan FEB UI announcements).
Tools: Pandas, RegEx, Tweepy.
